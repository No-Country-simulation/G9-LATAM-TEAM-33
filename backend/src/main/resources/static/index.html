Hackathon EnergiAI

⚡ EnergiAI - Java Backend API

Solución inteligente para el análisis, clasificación y optimización del consumo de energía eléctrica.

📌 Funcionalidades de la API

  • Clasificación: Categoriza el perfil energético en Eficiente, Moderado o Ineficiente.
  • Costo estimado: Cálculo del costo mensual según tarifa de referencia de $0,75 por kWh.
  • Modelos ML: Selección dinámica del algoritmo entre Random Forest (`rf`) y Regresión Logística (`lr`).
  • Indicadores: Consumo por equipo, por persona y por hora de alto consumo.
  • Recomendaciones: Sugerencias personalizadas con prioridad e impacto para reducir el gasto energético.

🌐 Endpoint Dinámico

                    -
                    

                        version 'v1' para modelo 'lr' o version 'v2' para modelo
                        'rf'
                    

                


                

                    POST
                    https://leafwatt.ddns.net/{version}/analisis-energetico
                


                

                    Campos del body (application/json):
                

                

                    
                        

                            Campo
                            Tipo
                            Descripción
                        

                    
                    
                        

                            consumo_kwh
                            Number
                            
                                Consumo mensual en kWh
                                requerido
                            
                        

                        

                            
                                uso_horario_pico
                            
                            Boolean
                            
                                Si hay consumo en horario pico
                                requerido
                            
                        

                        

                            
                                horas_alto_consumo
                            
                            Integer
                            
                                Horas diarias de alto consumo
                                requerido
                            
                        

                        

                            
                                cantidad_equipos
                            
                            Integer
                            
                                Cantidad de equipos eléctricos
                                requerido
                            
                        

                        

                            
                                cantidad_personas
                            
                            Integer
                            
                                Personas que utilizan el inmueble
                                requerido
                            
                        

                        

                            
                                tipo_inmueble
                            
                            String
                            
                                Casa, Departamento o Comercio
                                requerido
                            
                        

                        

                            mes
                            Integer
                            
                                Mes analizado (1-12)
                                requerido
                            
                        

                    
                

            


            
            

                

                    📤 Ejemplo de Request
                    200 OK
                

                
Body enviado a la API:

                
{
  "consumo_kwh": 450,
  "uso_horario_pico": true,
  "horas_alto_consumo": 3,
  "cantidad_equipos": 9,
  "cantidad_personas": 6,
  "tipo_inmueble": "Casa",
  "mes": 7
}

                    ⚠️ Ejemplo de Error de Validación

📜 Consultar Historial

                    200 OK
                


                

                    GET
                    https://leafwatt.ddns.net/historial
                


                

                    Devuelve el historial de análisis realizados, con paginación y filtro opcional por categoría.
                


                

                    
                        

                            Parámetro
                            Tipo
                            Descripción
                        

                    
                    
                        

                            categoria
                            String
                            
                                Filtra por categoría exacta (Eficiente, Moderado o Ineficiente)
                                opcional
                            
                        

                        

                            page
                            Integer
                            
                                Número de página, empieza en 0. Por defecto 0.
                                opcional
                            
                        

                        

                            size
                            Integer
                            
                                Cantidad de resultados por página. Por defecto 10.
                                opcional
                            
                        

                    
                


                
Ejemplo de Request:

                
GET /historial?categoria=Moderado&page=0&size=2


                
Ejemplo de Respuesta:

                
{
  "content": [
    { "id": 1, "categoria": "Moderado", "consumo_kwh": 450.0, "...": "..." }
  ],
  "total_elements": 3,
  "total_pages": 2,
  "number": 0,
  "size": 2
}
