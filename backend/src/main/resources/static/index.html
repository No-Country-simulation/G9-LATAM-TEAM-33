Hackathon EnergiAI

⚡ EnergiAI - Java Backend API, v3

Solución inteligente para el análisis, clasificación y optimización del consumo de energía eléctrica.

📌 Funcionalidades de la API

  • Clasificación: Categoriza el perfil energético en Eficiente, Moderado o Ineficiente.
  • Costo estimado: Cálculo del costo mensual según tarifa de referencia de $0,75 por kWh.
  • Indicadores: Consumo por equipo, por persona y por hora de alto consumo.
  • Recomendaciones: Sugerencias personalizadas con prioridad e impacto para reducir el gasto energético.

🌐 Endpoint

                

                    POST
                    /analisis-energetico
                


                

                    Campos del body (application/json):
                

                

                    
                        

                            Campo
                            Tipo
                            Descripción
                        

                    
                    
                        

                            consumo_kwh
                            Number
                            
                                Consumo mensual en kWh
                                requerido
                            
                        

                        

                            
                                uso_horario_pico
                            
                            Boolean
                            
                                Si hay consumo en horario pico
                                requerido
                            
                        

                        

                            
                                horas_alto_consumo
                            
                            Integer
                            
                                Horas diarias de alto consumo
                                requerido
                            
                        

                        

                            
                                cantidad_equipos
                            
                            Integer
                            
                                Cantidad de equipos eléctricos
                                requerido
                            
                        

                        

                            
                                cantidad_personas
                            
                            Integer
                            
                                Personas que utilizan el inmueble
                                requerido
                            
                        

                        

                            
                                tipo_inmueble
                            
                            String
                            
                                Casa, Departamento o Comercio
                                requerido
                            
                        

                        

                            mes
                            Integer
                            
                                Mes analizado (1-12)
                                requerido
